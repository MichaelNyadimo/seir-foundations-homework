Network Architecture — Personal VPC Design
============================================

Project: SEIR Foundations Module 1 — Network Architecture
AWS Region: us-east-1 (US East — N. Virginia)
Availability Zones: us-east-1a, us-east-1b, us-east-1c
VPC CIDR: 10.1.0.0/16

Subnet Design
-------------

| Subnet name         | Tier     | Availability Zone | CIDR           |
|---------------------|----------|-------------------|----------------|
| balerica-public-a   | Public   | us-east-1a        | 10.1.1.0/24    |
| balerica-public-b   | Public   | us-east-1b        | 10.1.2.0/24    |
| balerica-public-c   | Public   | us-east-1c        | 10.1.3.0/24    |
| balerica-private1-a | Private1 | us-east-1a        | 10.1.11.0/24   |
| balerica-private1-b | Private1 | us-east-1b        | 10.1.12.0/24   |
| balerica-private1-c | Private1 | us-east-1c        | 10.1.13.0/24   |
| balerica-private2-a | Private2 | us-east-1a        | 10.1.21.0/24   |
| balerica-private2-b | Private2 | us-east-1b        | 10.1.22.0/24   |
| balerica-private2-c | Private2 | us-east-1c        | 10.1.23.0/24   |

Design Notes
------------

- The VPC uses the private IPv4 range 10.1.0.0/16.
- Each subnet uses a /24 network.
- The three public subnets are distributed across three Availability Zones.
- The six private subnets are split into two private tiers, with one subnet from each tier in every Availability Zone.
- The subnet names identify the tier and Availability Zone.

Why I designed it this way
--------------------------

I chose a /16 for the VPC because it provides a large address space that can be divided into smaller subnets as the network grows. A /16 contains 65,536 total IPv4 addresses, while each /24 subnet contains 256 total addresses. AWS reserves five IPv4 addresses in every subnet, so each /24 has 251 usable addresses for resources. I placed one public subnet in each of three Availability Zones so public-facing resources can be distributed across zones, and I placed both private tiers in those same zones to keep the architecture organized and support separation between application tiers. You can identify the subnet tier from the third octet: 1–3 are public, 11–13 are Private1, and 21–23 are Private2. You can identify the Availability Zone from the final digit of the third octet: 1, 11, and 21 are in us-east-1a; 2, 12, and 22 are in us-east-1b; and 3, 13, and 23 are in us-east-1c.
